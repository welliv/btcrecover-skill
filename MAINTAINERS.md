## Becoming a Co-Maintainer

The project is intentionally open to trusted contributors. If you would like to become a co-maintainer:

1. Open a PR with meaningful contributions (new wallet support, security improvements, benchmark data, translations, etc.).
2. Demonstrate consistent, high-quality work over time.
3. Be added to `.github/CODEOWNERS` for the files you maintain.

All co-maintainers must follow the same security and attribution standards established in this repository.
