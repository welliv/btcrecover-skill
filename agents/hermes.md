# Hermes Setup

## Install

Clone the repo and load the skill:

```bash
git clone https://github.com/welliv/btcrecover-skill
skill load /path/to/btcrecover-skill/SKILL.md
```

Or from GitHub directly within Hermes:

```
skill load https://github.com/welliv/btcrecover-skill/raw/main/SKILL.md
```

## Usage

Describe your situation in plain English. The skill guides you through.

## Models

Hermes works well with local Ollama models. For maximum privacy, use Tier 1 (fully offline). See `guides/local-recovery-setup.md`.
