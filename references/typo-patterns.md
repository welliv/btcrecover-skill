# Password and Seed Word Error Pattern Library

## Common Password Errors
- Character substitutions (a→@, s→$, e→3, etc.)
- Missing characters at beginning/end
- Transposed adjacent characters
- Repeated characters
- Keyboard walks (qwerty, asdfgh)
- Common suffixes/prefixes (123, !@#, date)
- Case toggling

## Common Seed Word Errors
- Misspelled words (one letter off)
- Wrong word from same wordlist (similar shape/sound)
- Missing words
- Extra words
- Words in wrong order
- Words from wrong language wordlist

## Pattern Examples
- "password" → "p@ssw0rd", "Passw0rd!", "password123"
- "correct" → "corret", "correkt", "correct horse"
- "horse" → "h0rse", "horse ", " horseed"
