# Wallet Types Reference

## Supported Wallet Types
- Bitcoin Core (BTC)
- Electrum
- Ledger
- Trezor
- MetaMask (for BTC via bridges)
- Hardware wallets (general)

## Derivation Paths
- BIP44: m/44'/0'/0'/0/0
- BIP49: m/49'/0'/0'/0/0
- BIP84: m/84'/0'/0'/0/0

## Common Issues
- Wallet file corruption
- Password encoding issues
- Timestamp mismatches
